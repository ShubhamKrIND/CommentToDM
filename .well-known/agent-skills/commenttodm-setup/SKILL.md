# CommentToDM Setup Skill

## Description
Set up LinkedIn comment-to-DM automation using CommentToDM. This skill explains how to configure automated personalized DMs to everyone who comments a specific keyword on a LinkedIn post.

## What CommentToDM Does
CommentToDM monitors your LinkedIn posts for comments containing trigger keywords, then automatically sends a personalized direct message to each commenter. This is used by creators and B2B sellers to distribute lead magnets, files, or follow-ups at scale.

## Prerequisites
- A LinkedIn account
- $99/month subscription

## Setup Steps
1. Sign up at https://app.commenttodm.com/signup
2. Connect your LinkedIn account via OAuth
3. Create a new automation trigger:
   - Select the LinkedIn post to monitor
   - Set the keyword trigger (e.g. "guide", "template", "send")
   - Write your personalized DM template (use {{first_name}} for personalization)
4. Activate the automation — it runs 24/7

## DM Template Variables
- `{{first_name}}` — commenter's first name
- `{{post_url}}` — the URL of the post they commented on

## Example DM Template
```
Hey {{first_name}}, thanks for commenting! Here's the guide I mentioned: [link]

Let me know if you have questions.
```
